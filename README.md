# Face-Book-LogIn-Page
I created basic facebook login page using HTML and CSS . It is responsive and user friendly.

## Structure

The project consists of:
- `project1.html` - Main HTML structure
- `project1.css` - Styling and layout

## Features

- Login form with:
  - Email/phone input field 
  - Password input field
  - Login button
  - "Forgot Password?" link
  - "Create New Account" button
- Facebook branding and logo
- Responsive layout

## Implementation Notes

### HTML
- Uses semantic HTML5 elements
- Form validation attributes
- Proper input labels and accessibility

### CSS
- Flexbox layout
- Facebook's color scheme and typography
- Mobile-responsive design
- Input field styling
- Button styling and hover effects

## Usage

1. Clone the repository
2. Open `project1.html` in a web browser to view the login page
